# Flashlight

"Flashlight" by MAR.COS. — https://skfb.ly/o8H9O

Creative Commons Attribution 4.0 International:
https://creativecommons.org/licenses/by/4.0/

Adapted for this game: exported from the supplied Blender file to GLB,
textures resized to 1024 pixels, original scene rotation removed, and
scaled/positioned in a first-person view without hands. The game's beam
and battery behavior are controlled separately.

The original `.blend` and textures remain in `src/flashlight`.
Rebuild using portable Blender in background mode with `export-flashlight.py`.
