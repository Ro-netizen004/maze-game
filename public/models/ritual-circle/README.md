# Occult Ritual Circle – Stylized Prop

By ARTEL_3D: https://skfb.ly/pBDOJ

Creative Commons Attribution 4.0: https://creativecommons.org/licenses/by/4.0/

Source preserved in `src/occult-ritual-circle-stylized-prop`.
`export-ritual-circle.py` builds a 12,000-triangle browser copy with 1024-pixel
textures. The game scales/flattens the model into a walkable pad and adds glow
glyphs, markers, and activation effects. Geometry and textures are shared.
