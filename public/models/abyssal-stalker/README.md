# Abyssal Stalker

Original procedural creature built locally for this game, inspired by the user's reference.
This is not an export or copy of the paid Meshy model.

The GLB contains reusable primitive geometry, cyan details, and Idle, Walk, Run,
and Attack clips. It uses rigid mesh animation, without a skinned bone rig.

Source: src/game/guardian/deepSeaCreature.js
Regenerate: node scripts/assets/export-creature.mjs (from the project root).
