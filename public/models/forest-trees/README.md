# Realistic Trees Collection

By Jungle Jim — https://skfb.ly/pDzJR

Creative Commons Attribution 4.0 International:
https://creativecommons.org/licenses/by/4.0/

Game adaptation selects three tree varieties and one bush from the supplied
collection, resizes textures to 512 pixels, and exports a GLB. At runtime,
tree bases are centered/grounded, plants are scaled, foliage uses alpha cutouts,
and repeated plants share instanced geometry and materials.

Original GLB: `src/realistic_trees_collection.glb`, preserved unchanged.
Rebuild with Blender in background mode and `export-trees.py`.
