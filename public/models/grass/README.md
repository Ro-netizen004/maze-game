# Grass

"Grass" by Cosmic_dust — https://skfb.ly/p6tJE

Creative Commons Attribution 4.0 International:
https://creativecommons.org/licenses/by/4.0/

Game adaptation selects the Grass1 clump, converts the older material format
to metallic/roughness glTF materials, caps textures at 512 pixels, and uses
alpha cutouts and instancing. The game grounds, scales, rotates, and adds
gentle wind movement to the clumps. Reduced Motion stops the wind animation.

Original source preserved at `src/grass.glb`.
Rebuild with Blender background mode and `scripts/assets/export-grass.py`.
